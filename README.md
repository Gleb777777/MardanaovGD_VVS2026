дз2 — классная работа и домашка на уровни.py 
консольная программа по строковым методам Python, 5 уровней. Пользователь вводит номер уровня, программа показывает теорию и примеры, а затем применяет метод к строке.
  - Уровень 1: lower(), upper(), capitalize()
  - Уровень 2: find(), replace(), count()
  - Уровень 3: split(), join()
  - Уровень 4: isdigit(), isalpha(), strip(), lstrip(), rstrip(), format()
  - Уровень 5: комбинация методов, которая шаг за шагом приводит строку к нужному выводу

дз3 — задание игрушка лабиринт.py
- игра с системой передвижения по игровому полю (w,a,s,d). Каждая клетка поля - это комната, в которой может что-либо или кто-либо находиться (сундук с предметом, монстр, выход и т.д). Реализовано взаимодействие с монстром и сделана шкала здоровья (hp). Также у игрока есть инвентарь с ограниченной вместимостью (в инвентарь попадают предметы которые выпали из сундука). При 'рандомном' достижении клетки "выхода" персонаж выбирается из лабиринта и игра завершается.
